# BMI Calculator Project

## Overview
This project is a BMI (Body Mass Index) calculator built using HTML, CSS, and JavaScript. It allows users to input their weight and height to calculate their BMI and provides immediate feedback based on the calculated value.

## Project Structure
```
bmi-calculator
├── index.html
├── css
│   └── styles.css
├── js
│   └── script.js
└── README.md
```

## File Descriptions

- **index.html**: Contains the HTML structure for the BMI calculator. This file includes forms for user input (weight and height), a button to calculate BMI, and sections to display the results.

- **css/styles.css**: Contains the CSS styles for the BMI calculator. It defines the layout, colors, fonts, and overall appearance of the application.

- **js/script.js**: Contains the JavaScript code for the BMI calculator. It includes functions to handle user input, perform the BMI calculation, and update the results displayed on the webpage.

- **README.md**: This documentation file provides setup instructions, usage guidelines, and other relevant information about the project.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Open `index.html` in a web browser to use the BMI calculator.

## Usage Guidelines
- Input your weight in kilograms and height in meters.
- Click the calculate button to see your BMI result.
- The application will provide feedback based on the calculated BMI value.
